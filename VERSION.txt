--------------------------------------------------------------------------------
v1.0 — versión base
--------------------------------------------------------------------------------
Funciones base:
- Gestión de evaluaciones escolares/universitarias.
- Generación de resúmenes con IA (Groq API, texto y visión).
- Flashcards para estudiar y modo examen.
- Planificación de estudio automática con IA.
- Persistencia local con Hive (evaluaciones, settings, consentimiento
  legal, historial).

Stack: Flutter/Dart + Groq API + Firebase (Cloud Firestore).

--------------------------------------------------------------------------------
v2.0 — Autenticación custom + red social + mensajería + actualizaciones OTA
--------------------------------------------------------------------------------
- Login custom (usuario/contraseña, hash SHA-256 + salt), sin Firebase Auth.
- Cuentas vinculadas a dispositivo, panel de administración de usuarios.
- Red social interna entre estudiantes: feed, perfiles, follows.
- Mensajería directa.
- Actualizaciones forzadas por versión mínima + distribución OTA vía APK.
- Detección real de conectividad.

Ver INFORME.txt para el detalle técnico completo (arquitectura, pantallas,
pendientes conocidos).
